# BF6 Universal Optimizer 0.1.0-beta.1

First native Windows release. This is a prerelease.

## Highlights

- **Battlefield 6 configuration:** recommendations for your hardware, before/after preview, backup, verification and automatic rollback
- **Hardware analysis:** CPU, GPU, memory and display detection without a fixed model list
- **Windows gaming audit:** a configuration health score with its coverage, and evidence for each check
- **Network diagnostics:** regional latency tests, route analysis, live monitoring and a server IP manager
- **Backup and restore:** original baseline, snapshots, SHA-256 verification and support for v1.4.0 backups
- **Portable:** one executable with no installation, no .NET install and no administrator rights

## Known limitations

- Run on one Windows 11 desktop only. Not yet tested on a clean machine, Windows 10, laptops, AMD or Intel GPUs, multi-monitor setups or display scaling above 100 %.
- Apply and restore have been tested with fixtures, not with live game profiles.
- The desktop UI automation suite has no complete passing run on this build.
- XMP, EXPO, PBO, Resizable BAR and driver panel settings cannot be verified from Windows.
- Regional latency tests measure AWS network probes, not Battlefield servers. Automatic detection of the live game server is unsupported.
- FPS and frame times are not measured.
- The executable is not code-signed.

## Verify your download

```powershell
Get-FileHash .\BF6Optimizer.exe -Algorithm SHA256
```

Compare the result with `SHA256SUMS.txt`.
