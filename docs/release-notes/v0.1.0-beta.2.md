# BF6 Universal Optimizer 0.1.0-beta.2

Bug fix prerelease.

## Fixed

- Hardware Information: "Detect again" no longer empties the Gaming GPU and Gaming display dropdowns.
- Hardware Information: "Detect again" now shows a result with the time, a progress bar, and an error message if detection fails.
- Display Analyzer: the gaming display selection is kept when hardware data reloads.

## Known limitations

- Run on one Windows 11 desktop only. Not yet tested on a clean machine, Windows 10, laptops, AMD or Intel GPUs, multi-monitor setups or display scaling above 100 %.
- Apply and restore have been tested with fixtures, not with live game profiles.
- The desktop UI automation suite has no complete passing run on this build.
- XMP, EXPO, PBO, Resizable BAR and driver panel settings cannot be verified from Windows.
- Regional latency tests measure AWS network probes, not Battlefield servers. Automatic detection of the live game server is unsupported.
- FPS and frame times are not measured.
- The executable is not code-signed.

## Verify your download

```powershell
Get-FileHash .\BF6Optimizer.exe -Algorithm SHA256
```

Compare the result with `SHA256SUMS.txt`.
