## 0.1.0-beta.1

First native release, replacing the earlier PowerShell package.

- Native C# and WPF application in a single self-contained executable
- Battlefield 6 configuration optimizer with preview, backup, verification and rollback
- Windows gaming audit with configuration health score and assessment coverage
- Memory, CPU, GPU, display, storage, network, process and startup analysis
- Live monitoring and performance sessions
- Regional latency tests, route analysis and server IP manager
- Reports in HTML, JSON and text, with a privacy review
- English and Turkish interface, dark and light themes, responsive layout
